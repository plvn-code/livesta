# LIVESTA ONE — магазин косметики LIVESTA (@__livesta__one)

Client site for a LIVESTA reseller in Izmail («Магазин Livesta», Instagram @__livesta__one, Telegram t.me/+WJZA750qS1FhZGIy, wholesale available). Sells skincare / cosmetology cosmetics plus the rest of the LIVESTA catalogue.

Brief from the user: classy, expensive, animated site in the style of charlottetilbury.com and soulbeauty.com.ua; client colours **pink, beige, black**; **product photos always on white**. Catalogue = the client's PDF (`~/Downloads/catalog.pdf`, LIVESTA catalogue 28.11–25.12, 155 spreads).

**Talk to the user in Russian.** Site copy is **Ukrainian only** (`lang="uk"`, ’ apostrophes, «» quotes). Read `docs/STATUS.md` first (open client questions).

## Commands
```bash
npm run build && npm start               # production on :3015
kill $(lsof -ti tcp:3015 -sTCP:LISTEN)   # restart: only our port, only LISTEN
npm run lint && npx tsc --noEmit         # must stay clean
open -a "Google Chrome" http://localhost:3015
# data pipeline (research/.venv has pymupdf, Pillow, numpy, imageio-ffmpeg)
research/.venv/bin/python -I /path/dump.py ~/Downloads/catalog.pdf research/pdf_text.json   # see scripts/ for the real steps:
research/.venv/bin/python -I scripts/fetch_search.py .   # every PDF code → livesta.ua search JSON (research/search)
research/.venv/bin/python -I scripts/fetch_pages.py .    # product pages (research/html) + original photos (originals/)
research/.venv/bin/python -I scripts/catalog.py          # → src/data/catalog.json + public/images/p (cached; delete a file to rebuild)
research/.venv/bin/python -I scripts/build_video.py .    # Pexels clips → public/video + posters
```

## New catalogue period (every ~4 weeks)
1. Put the new PDF somewhere, extract codes: text with U+0349–U+0352 → digits 0–9 (the PDF obfuscates digits in some fonts), all 6-digit numbers → `research/codes.json` (code → pages).
2. Delete `research/search/*.json` (prices change!), run fetch_search, fetch_pages, catalog.py.
3. Update `site.catalogue` in `src/lib/site.ts` (from / to / until).
Prices come from livesta.ua search (`price` = «Крута ціна», `price_black` = old price); checked against the PDF: 1055/1070 identical, the rest were PDF-parser misses (`scripts/pdf_prices.py`).

## Stack
Next.js 15 App Router · React 19 · TypeScript strict · plain CSS (`src/app/globals.css`, tokens in `:root`) · Cormorant Garamond self-hosted in `src/app/fonts.css` (next/font could not parse Google's response) + Manrope via next/font · no animation libraries (`src/lib/motion.ts`, `src/components/Effects.tsx`, `src/components/home/Motion.tsx`). Everything respects `prefers-reduced-motion`. Pre-built WebP → plain `<img>` (lint rule off).

Images: `public/images/p/<code>.webp` (900, product re-centred on white), `<code>s.webp` (420), `<code>-<n>.webp` (extra photos), `<code>c.webp` (cut-out with alpha, for coloured blocks). Home-page cut-out picks are ids in `src/app/page.tsx` (fallback: first cut-outs of the section).
Client components must not import `src/lib/catalog.ts`.
